使い方とお問い合わせ

1. 住所録に人を足す

ホームの［人を足す］で、名前・ふりがな・郵便番号・住所を入れます。郵便番号を7桁入れると、都道府県・市区町村・町が出ます（同じ郵便番号に町がいくつかあるときは選びます）。番地と建物は住所の欄に続けて入れてください。

  • 連名は3人まで。名字は1つで、名前だけを入れます
  • 会社あてなら、会社名・部署・担当者を入れます。担当者がいれば、会社名に「御中」をつけず、担当者に「様」をつけます（担当者の欄に「様」を入れる必要はありません）
  • 敬称は 様・御中・先生・殿・なし から選べます。「なし」は何も書きません
  • 連絡先から選んで入れる・CSV から読みこむこともできます（CSV は、どの列が名前・郵便番号・住所かを選びます）

2. 差出人

ホームの上の［差出人］で、家族用・仕事用など、差出人を何人でも作れます。差出人を印刷するかどうかも選べます。差出人の郵便番号は、住所の上に「〒」をつけて書きます。

3. 印刷する

  1. ホームの右下の［印刷する］を押します
  2. 出す人を選びます（グループで全部・1人ずつ）
  3. 用紙を選びます（はがき・往復はがき・長形3号・長形4号・角形2号・洋形2号）
  4. 下見で、実寸の用紙の形で確かめます。1人ずつめくれます
  5. ［印刷］（AirPrint のプリンター）か［PDF にする］

下見と印刷と PDF は同じ描き方なので、大きさがずれません。プリンターの用紙の設定は、選んだ用紙の大きさになります。

4. 位置がずれるとき（試し刷りと微調整）

下見の［試し刷り］で、普通紙に郵便番号の枠の線と用紙のふちを印刷します。その上にはがきを重ねて、ずれを確かめてください。［用紙の微調整］で、郵便番号の枠の上下左右と、全体の上下左右を 0.5mm ずつ動かせます。用紙ごとに覚えます。

5. 今年の印

住所録の行を長押しすると、今年の印（出した・届いた・喪中）を切りかえられます。喪中の人を除いて選ぶときに使えます。

6. データを守る

  • iCloud に入っている端末では、毎日の控えを iCloud Drive に置きます（30日・どの日にも戻せます）
  • ［控えのファイルを書き出す］で、ファイル（.fumibako）に保存できます。機種変更や Android との移し替えに使えます。CSV でも書き出せます
  • 消した人はゴミ箱に30日あります

よくあるご質問

プリンターに、はがきの大きさが出てきません

AirPrint に対応したプリンターでも、はがきや封筒の大きさを持たない機種があります。そのときは［PDF にする］で PDF を作り、プリンターの会社のアプリなどから印刷してください。

本当にどこにも送らないのですか

ふみばこは登録もログインもなく、通信をしません（Android 版はインターネットの権限を持ちません）。郵便番号から住所を出すのも、端末の中のデータで行います。PDF を送るのは、あなたが共有シートで選んだときだけです。

郵便番号のデータはいつのものですか

アプリの［設定］→［このアプリについて］に、取りこんだ日付を出しています。郵便番号が変わったときは、アプリの版を上げるときにデータを新しくします。

Help & Contact

1. Add people to the address book

Tap Add Person on the home screen and enter the name, reading, postal code and address. Type the 7-digit postal code and the prefecture, city and town appear (choose one when a code covers several towns). Add the block number and building to the address.

  • Up to three joint names: one family name, given names only
  • For a company, enter the company, department and contact person. With a contact person, the company gets no "Onchu" and the person gets "Sama" (don't type "Sama" yourself)
  • Honorifics: Sama, Onchu, Sensei, Dono or none ("none" prints nothing)
  • You can also add people from Contacts or import CSV (choose which columns are the name, postal code and address)

2. Senders

Tap Sender at the top of the home screen to make as many senders as you like (family, work). You can choose whether to print the sender. The sender's postal code is written above the address with "〒".

3. Print

  1. Tap Print at the bottom right of the home screen
  2. Choose who to send to (a whole group or one by one)
  3. Choose the paper (postcard, reply-paid postcard, Naga 3, Naga 4, Kaku 2, You 2)
  4. Check the full-size preview; flip through one by one
  5. Print (AirPrint) or Make PDF

The preview, printing and PDF use the same drawing, so sizes never drift. The printer is given the size of the paper you chose.

4. When the position is off (test print and fine-tune)

Test Print in the preview prints the postal-code box lines and the paper edge on plain paper. Lay the postcard over it to check. In Fine-tune Paper, move the postal-code boxes and the whole address up, down, left or right in 0.5 mm steps. Each paper remembers its own values.

5. This year's marks

Touch and hold a row in the address book to switch this year's mark (sent, received, in mourning). Use it to leave out people in mourning.

6. Keep your data safe

  • On devices signed in to iCloud, a daily backup goes to iCloud Drive (30 days, restore any day)
  • Export Backup File saves a .fumibako file for moving to a new phone or to Android. CSV export is also available
  • Deleted people wait in the trash for 30 days

FAQ

My printer has no postcard size

Some AirPrint printers don't offer postcard or envelope sizes. Use Make PDF and print it from your printer maker's app.

Does it really send nothing?

Fumibako has no account or login and makes no network connections (the Android version has no internet permission). Postal codes are looked up from data on the device. A PDF leaves the device only when you share it.

How current is the postal code data?

Settings → About this App shows the date the data was imported. When postal codes change, the data is refreshed with an app update.
